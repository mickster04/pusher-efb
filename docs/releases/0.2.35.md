# Push Planner 0.2.35

Pre-release patch. Fixes for the ATR 72-600 and the Cessna Caravan, found in the sim logs. See also the [first-release notes draft](../release-notes.md) and the [release checklist](../release-checklist.md).

## Changes

- **ATR 72-600: beacon.** The ATR's beacon switch cannot be read or set by the app, so the aircraft now has a profile that hides the beacon step, the beacon wait and the BEACON pill. Pushes on the ATR no longer wait for a beacon that cannot be seen. Other aircraft are unchanged.
- **Parking brake: Ignore the parking brake.** A new choice in Settings > Parking brake (Wait for / Ignore). Ignore skips the brake step, the wait for the brake to be off and the stop when the brake is set during a push. Use it for an aircraft whose brake the app cannot read. The default is still to wait.
- **Parking brake: slower aircraft.** After the brake is released the app now waits up to 12 s (it was 4 s) for the aircraft to answer, and sends the toggle only once. Some aircraft answer several seconds late, and a second toggle would set the brake again.
- **Tug pill after Finish.** The TUG pill, the Dismiss button and Stop now read the tug from the sim on every repaint. Before, the pill could keep showing TUG ON after the tug had been dismissed (seen on the Caravan).
- **Route log.** At the start of a push the log now lists each leg (push back or forward, length, end point and heading), so a plan that behaved oddly can be reproduced from a log.
- **Package.** The package title is now "Push Planner".
- **Docs.** README, design notes, release checklist and first-release notes brought up to date; Known issues added to the README.

## Known issues

- On the ATR, a joystick, yoke or pedal button bound to the parking brake can flip the brake during a push and stop it. Remove the binding, or use Ignore the parking brake.
- For some end-pin headings the planner adds a short forward leg that retraces ground just covered. Left as is: it is rare and harmless.

## Verified

Unit tests pass (153). Not yet run in the sim: the ATR with its brake binding removed, the hidden beacon, the Ignore setting, and the TUG OFF pill after Finish.
